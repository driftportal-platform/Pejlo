# Pejlo · 0.3.0

Dansk mobilprototype til flere dyr og genstande.
Læs **START_HER.md** for GitHub-upload og Cloudflare-opsætning.

- Kat, hund, hest, andre dyr, bil, cykel og andre genstande.
- Egne navne, faste SVG-ikoner og separat hjemmepunkt pr. profil.
- Søgning fra mobilens placering med meter, retning, valgfrit kompas og automatisk zoom.
- Kortlag med MapTiler-nøgle samt lokal skematisk kortdemo.
- Ingen login- eller Traccar-forbindelse endnu. Alle målpositioner er eksempeldata.

`npm run build` bygger dist. `npm test` bygger og kører tests.

Brug kildefilerne i apps/web og packages/shared, når appen ændres. Dist genereres automatisk.
