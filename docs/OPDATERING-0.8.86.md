# Pejlo 0.8.86

Find-knappen er flyttet fra oplysninger til selve kortets øverste venstre hjørne. Knappen bruger den eksisterende søgevisning og følger den valgte profils navn. Centrering og kortmenu forbliver til højre.

Kort, Hjemmeområde og Oplysninger er igen synlige direkte over kortet, også når Kort er valgt. Rækken kan rulles vandret på smalle skærme.

Pakken lægges oven på 0.8.85. GPS-filtrering, hvilestop og trackerens rapporteringsinterval er uændrede.
