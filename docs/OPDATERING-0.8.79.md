# Pejlo 0.8.79

Kortet kommer nu før hvileknappen, hvileloggen og øvrige kortfunktioner på både mobil og computer. Tidligere mobilregler gav kortet en senere placering end hvilepanelet, selv om kortet stod først i sidens HTML.

De tre kortmenuer står i én kompakt række. Ved stor tekst eller en smal skærm kan rækken rulles vandret. På kortsiden fylder kontobjælken mindre på mobil; serverstatus og synkronisering er fortsat synlige. E-mailen vises på de øvrige sider. Loui-profilen og dens statusikoner bevares.

Pakken kan lægges oven på 0.8.77 eller 0.8.78 og indeholder også hvilerettelsen fra 0.8.78. Upload med samme mapper som i ZIP-filen. Trackerens indstillinger og appens beregninger er ikke ændret i denne layoutrettelse.

Validering: Build gennemført. Den seneste beregnings- og funktionstest har 366 beståede tests. Den visuelle placering skal kontrolleres på den installerede app efter upload.
