# Pejlo 0.8.10

Under Indstillinger → Område → Cirkel vises nu »Vælg cirkel på kortet«. Den åbner korteditoren med det indtastede navn, radius, ekstra margen, koordinater og overvågningsvalg. Tryk på kortet for at vælge centrum, justér radius med skyderen, og tryk Gem hjemmeområde. Annullering ændrer ikke det gemte område. Polygonens punkttæller skjules, når cirkel er valgt.

Punkter beholder den eksisterende tegnefunktion. Rettelserne fra 0.8.9 er bevaret. Ingen databaseændringer eller nye nøgler.

Validering: build og 98 automatiske tests bestået. Ikke visuelt testet på fysisk iPhone. Efter upload: prøv cirkel fra Område, flyt centrum, justér radius, annullér og åbn igen. Prøv derefter at gemme, og kontrollér den gemte cirkel på Kort. Skift til punkter og tilbage til cirkel; punkttælleren skal kun være synlig ved punkter.
