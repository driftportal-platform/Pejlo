# Pejlo 0.8.77

Kort har nu menupunkterne Kort, Hjemmeområde og Oplysninger. Kortet, hvileknappen og kortets handlinger ligger under Kort. Loui-profilens status og ikoner er bevaret.

Ture har menupunkterne Overblik, Grafer, Dagstal, Rutehistorik og Alarmer. Grafer og formularer bruger de samme data som før. Rediger i dagstabellen åbner registreringen under Dagstal. For genstande vises Rutehistorik og Alarmer; dyrenes motion og hvile vises kun for dyreprofiler.

Menupunkterne kan betjenes med piletaster samt Home og End. På mobil fordeles knapperne over flere linjer. Skift væk fra rutehistorikken stopper afspilningen; kortet tilpasser størrelsen, når det åbnes igen.

Denne ændringspakke kan lægges oven på 0.8.75 eller 0.8.76. Den indeholder også rettelsen fra 0.8.76 til automatisk stop af manuel hvile og kontrol af gemt positionshistorik. Upload filerne med samme mapper som i ZIP-filen og lad det normale Cloudflare-build køre. Bevar dine eksisterende miljøvariabler og kortnøgle.

Kontrol: 364 automatiske tests bestået. Navigationens valg, tastaturbetjening og genstandsprofiler er testet. Den færdige visning er ikke kontrolleret i en interaktiv browser i denne arbejdssession.
